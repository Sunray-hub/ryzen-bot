# Ryzen Bot

**Ryzen Bot** is a conversational Discord bot powered by Google Gemini. It allows users to chat naturally with the bot directly in Discord.

## ⚙️ Setup

To run the bot, create a `.env` file in the project directory and add your API tokens:

```env
GEMINI_TOKEN="your_gemini_api_key"
DISCORD_TOKEN="your_discord_bot_token"
```

Then start the bot with Python.

> **⚠️ Keep your `.env` file private.** Never commit your tokens or API keys to GitHub.
